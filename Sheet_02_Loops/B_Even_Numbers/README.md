<h2><a href="https://codeforces.com/group/MWSDmqGsZm/contest/219432/problem/B">B. Even Numbers</a></h2>
<h3>Sheet #2 (Loops) — ICPC Assiut University Community</h3>
<hr>

<p><strong>Time Limit:</strong> 1 second &nbsp;|&nbsp; <strong>Memory Limit:</strong> 256 megabytes</p>

<div><p>Given a number <span class="tex-span"><i>N</i></span>. Print all <span class="tex-font-style-bf">even</span> numbers between <span class="tex-font-style-bf">1</span> and <span class="tex-font-style-bf"><span class="tex-span"><i>N</i></span></span> inclusive in separate lines.</p></div>

<h3>Input</h3>
<div class="section-title">Input</div><p>Only one line containing a number <span class="tex-span"><i>N</i></span> <span class="tex-span">(1 ≤ <i>N</i> ≤ 10<sup class="upper-index">3</sup>)</span>.</p>

<h3>Output</h3>
<div class="section-title">Output</div><p>Print the answer according to the required above. If there are no <span class="tex-font-style-bf">even</span> numbers print <span class="tex-font-style-bf">-1</span>.</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
10
<strong>Output:</strong>
246810
</pre>
