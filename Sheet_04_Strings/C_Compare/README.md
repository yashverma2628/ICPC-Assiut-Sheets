<h3>Sheet #4 (Strings) — ICPC Assiut University Community</h3>
<hr>

<p><strong>Time Limit:</strong> 1 second &nbsp;|&nbsp; <strong>Memory Limit:</strong> 256 megabytes</p>

<div><p>Given two strings <span class="tex-span"><i>X</i></span> and <span class="tex-span"><i>Y</i></span> . Print the <span class="tex-font-style-bf">smallest lexicographical</span> one. </p><p><span class="tex-font-style-bf">Note:</span> <span class="tex-font-style-bf">Lexicographical</span> is the way of ordering the words based on the alphabetical order of their component letters.</p></div>

<h3>Input</h3>
<div class="section-title">Input</div><p>Only one line contains two strings <span class="tex-span"><i>X</i>, <i>Y</i>(1 ≤ |<i>X</i>|, |<i>Y</i>| ≤ 20)</span> consists of lowercase English letters.</p>

<h3>Output</h3>
<div class="section-title">Output</div><p>Print the <span class="tex-font-style-bf">smallest lexicographical</span> string.</p><p><span class="tex-font-style-bf">Note:</span> If both of <span class="tex-span"><i>X</i></span> and <span class="tex-span"><i>Y</i></span> are equal, print any of them.</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
acmacpc
<strong>Output:</strong>
acm
</pre>

<h3>Note</h3>
<div class="section-title">Note</div><p>For more information visit Lexicographical order: <a href="https://en.wikipedia.org/wiki/Lexicographical_order">https://en.wikipedia.org/wiki/Lexicographical_order</a></p>
