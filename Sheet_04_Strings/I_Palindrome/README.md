<h2><a href="https://codeforces.com/group/MWSDmqGsZm/contest/219856/problem/I">I. Palindrome</a></h2>
<h3>Sheet #4 (Strings) — ICPC Assiut University Community</h3>
<hr>

<p><strong>Time Limit:</strong> 1 second &nbsp;|&nbsp; <strong>Memory Limit:</strong> 256 megabytes</p>

<div><p>Given a string <span class="tex-span"><i>S</i></span>. Determine whether <span class="tex-span"><i>S</i></span> is <span class="tex-font-style-bf">Palindrome</span> or <span class="tex-font-style-bf">not</span></p><p><span class="tex-font-style-bf">Note:</span> A string is said to be a <span class="tex-font-style-bf">palindrome</span> if <span class="tex-font-style-bf">the reverse</span> of the string is <span class="tex-font-style-bf">same</span> as the string. For example, "abba" is <span class="tex-font-style-bf">palindrome</span>, but "abbc" is not <span class="tex-font-style-bf">palindrome</span>.</p></div>

<h3>Input</h3>
<div class="section-title">Input</div><p>Only one line contains a string <span class="tex-span"><i>S</i></span> <span class="tex-span">(1 ≤ |<i>S</i>| ≤ 1000)</span> where |S| is the length of the string and it consists of <span class="tex-font-style-bf">lowercase</span> letters only.</p>

<h3>Output</h3>
<div class="section-title">Output</div><p>Print "<span class="tex-font-style-bf">YES</span>" if the string is <span class="tex-font-style-bf">palindrome</span>, otherwise print "<span class="tex-font-style-bf">NO</span>".</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
abba
<strong>Output:</strong>
YES
</pre>
