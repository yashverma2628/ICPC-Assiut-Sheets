<h2><a href="https://codeforces.com/group/MWSDmqGsZm/contest/219856/problem/G">G. Conversion</a></h2>
<h3>Sheet #4 (Strings) — ICPC Assiut University Community</h3>
<hr>

<p><strong>Time Limit:</strong> 2 seconds &nbsp;|&nbsp; <strong>Memory Limit:</strong> 64 megabytes</p>

<div><p>Given a string <span class="tex-span"><i>S</i></span>. Print the <span class="tex-font-style-bf">origin</span> string after replacing the following:</p><ul> <li> Replace every <span class="tex-font-style-bf">comma</span> character ',' with a space character. </li><li> Replace every <span class="tex-font-style-bf">capital character</span> in <span class="tex-span"><i>S</i></span> with its respective <span class="tex-font-style-bf">small character</span> and <span class="tex-font-style-bf">Vice Versa</span>. </li></ul></div>

<h3>Input</h3>
<div class="section-title">Input</div><p>Only one line contains a string <span class="tex-span"><i>S</i></span> <span class="tex-span">(1 ≤ |<i>S</i>| ≤ 10<sup class="upper-index">5</sup>)</span> where |S| is the length of the string and it consists of <span class="tex-font-style-bf">lower</span> and <span class="tex-font-style-bf">upper</span> English letters and <span class="tex-font-style-bf">comma</span> character ','. </p>

<h3>Output</h3>
<div class="section-title">Output</div><p>Print the string after the <span class="tex-font-style-bf">conversion</span>.</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
happy,NewYear,enjoy
<strong>Output:</strong>
HAPPY nEWyEAR ENJOY
</pre>
