<h2><a href="https://codeforces.com/group/MWSDmqGsZm/contest/219856/problem/A">A. Create A New String</a></h2>
<h3>Sheet #4 (Strings) — ICPC Assiut University Community</h3>
<hr>

<p><strong>Time Limit:</strong> 1 second &nbsp;|&nbsp; <strong>Memory Limit:</strong> 256 megabytes</p>

<div><p>Given two strings <span class="tex-span"><i>S</i></span> and <span class="tex-span"><i>T</i></span>. Print <span class="tex-font-style-bf">2</span> lines that contain the following in the same order:</p><ol> <li> Print the <span class="tex-font-style-bf">length</span> of <span class="tex-span"><i>S</i></span> and <span class="tex-span"><i>T</i></span> separated by space. </li><li> Print a <span class="tex-font-style-bf">new string</span> that contains <span class="tex-span"><i>S</i></span> and <span class="tex-span"><i>T</i></span> separated by a space. </li></ol><p><span class="tex-font-style-bf">For more clarification see the example below</span>.</p></div>

<h3>Input</h3>
<div class="section-title">Input</div><p>The first line contains a string <span class="tex-span"><i>S</i></span> <span class="tex-span">(1 ≤ |<i>S</i>| ≤ 10<sup class="upper-index">3</sup>)</span> where <span class="tex-span">|<i>S</i>|</span> is the length of <span class="tex-span"><i>S</i></span>.</p><p>The second line contains a string <span class="tex-span"><i>T</i></span> <span class="tex-span">(1 ≤ |<i>T</i>| ≤ 10<sup class="upper-index">3</sup>)</span> where <span class="tex-span">|<i>T</i>|</span> is the length of <span class="tex-span"><i>T</i></span>.</p>

<h3>Output</h3>
<div class="section-title">Output</div><p>Print the answer required above. </p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
LEVELONE
<strong>Output:</strong>
5 3LEVEL ONE
</pre>
