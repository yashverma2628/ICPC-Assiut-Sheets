<h2><a href="https://codeforces.com/group/MWSDmqGsZm/contest/219856/problem/E">E. Count</a></h2>
<h3>Sheet #4 (Strings) — ICPC Assiut University Community</h3>
<hr>

<p><strong>Time Limit:</strong> 2 seconds &nbsp;|&nbsp; <strong>Memory Limit:</strong> 64 megabytes</p>

<div><p>Given a string <span class="tex-span"><i>S</i></span>. Print the <span class="tex-font-style-bf">summation</span> of its digits.</p></div>

<h3>Input</h3>
<div class="section-title">Input</div><p>Only one line contains a string <span class="tex-span"><i>S</i></span> <span class="tex-span">(1 ≤ |<i>S</i>| ≤ 10<sup class="upper-index">6</sup>)</span> where |S| is the length of the string.</p><p><span class="tex-font-style-bf">It's guaranteed that <span class="tex-span"><i>S</i></span> contains only digits from 0 to 9.</span></p>

<h3>Output</h3>
<div class="section-title">Output</div><p>Print the answer required above.</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
351
<strong>Output:</strong>
9
</pre>

<h3>Note</h3>
<div class="section-title">Note</div><p>First Test :</p><p>3 + 5 + 1 = 9 .</p>
