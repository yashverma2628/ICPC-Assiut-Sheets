<h3>Sheet #4 (Strings) — ICPC Assiut University Community</h3>
<hr>

<p><strong>Time Limit:</strong> 1 second &nbsp;|&nbsp; <strong>Memory Limit:</strong> 64 megabytes</p>

<div><p>Given a string S. Print the string <span class="tex-span"><i>S</i></span> from the beginning to the first '\' character without printing the '\'.</p><p><span class="tex-font-style-bf">Hint:</span> use function <span class="tex-font-style-bf">getline(cin, s)</span>.</p></div>

<h3>Input</h3>
<div class="section-title">Input</div><p>Only one line contains a string <span class="tex-span"><i>S</i></span> <span class="tex-span">(1 ≤ |<i>S</i>| ≤ 10<sup class="upper-index">6</sup>)</span> where |S| is the length of the string.</p><p><span class="tex-font-style-bf">It's guaranteed that <span class="tex-span"><i>S</i></span> will contain '\' symbol</span>.</p>

<h3>Output</h3>
<div class="section-title">Output</div><p>Print the answer required above.</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong>
Egyptian collegiate programming\ contest
<strong>Output:</strong>
Egyptian collegiate programming
</pre>
